# Changelog

## [0.1.0] - 2026-08-16

### Added

- HTML, Markdown, WordPress REST payload, and standalone JSON-LD parsing.
- SEO metadata, page structure, social preview, media, and link checks.
- Schema graph expansion and property checks for common schema.org types.
- Multilingual content units with CJK-aware counting.
- Console, JSON, and SARIF reporting with configurable quality gates.
- Dependency-free Python API and command-line interface.
