# Contributor Covenant Code of Conduct

We pledge to make participation in this project a harassment-free experience
for everyone. Be respectful, accept constructive feedback, and focus on what is
best for the community.

Harassment, trolling, personal attacks, and publishing private information
without permission are unacceptable. Project maintainers may remove, edit, or
reject contributions and interactions that violate these standards.

Report conduct concerns through the repository's private security channel.
This text is adapted from Contributor Covenant 2.1.
