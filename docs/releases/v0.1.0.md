# Content SEO Schema Checker 0.1.0

The first alpha release adds a dependency-free pre-publish quality gate for
HTML, Markdown, WordPress REST payloads, and standalone JSON-LD.

Highlights:

- deterministic SEO metadata and page-structure rules;
- JSON-LD syntax, context, type, graph, and property checks;
- WordPress and Yoast field extraction;
- multilingual content measurement with CJK support;
- console, JSON, and GitHub-compatible SARIF reports;
- configurable thresholds, rule disabling, severity overrides, and required
  schema types.
